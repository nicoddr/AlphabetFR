## Modifications Globales Appliquées
- **Suppression des guides de prononciation** : Toutes les indications de prononciation phonétique (comme pour le japonais, le coréen, le dari, etc.) ont été retirées à la demande de l'utilisateur pour conserver un rendu visuel épuré.
- **Barre de recherche dans le sélecteur** : Une zone d'entrée de recherche en temps réel a été ajoutée au sélecteur de langue en haut à droite afin de faciliter le filtrage des 73 langues.
